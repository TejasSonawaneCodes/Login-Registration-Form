Responsive Login & Registration Form 💻 

This is a simple and modern Responsive Login and Registration Form built using HTML, CSS, and vanilla JavaScript. The design adapts smoothly to different screen sizes, making it suitable for both desktop and mobile devices.


🔥 Features : 
Clean and minimalistic UI

Fully responsive layout

Smooth transitions between login and registration forms

Social media icons included (Facebook, Google, Twitter)

Hover effects and gradient buttons

Toggle between Login and Register using JavaScript


📁 Project Structure :
.
├── index.html        # Main HTML file
├── style.css         # Styling file


🎨 Customization :
Change colors, fonts, or icons in the style.css file as per your needs.

You can integrate the form with your backend for authentication and user registration.


🛠 Technologies Used : 
HTML5

CSS3 (Flexbox, Media Queries)

JavaScript (for form switching)

Boxicons for icons
